# Jogo2d
Um pequeno projeto de jogo2d utilizando uma mini-engine própria
---

### Pré-Requisitos:
* **Framework Love2d**
* **Visual Studio Code**
* **Linguagem LuaJIT**

### Passo a Passo:
1. Baixar o VSCode
2. Clonar o projeto usando Git
3. Baixar o Love2D
4. Baixar a extensão Love2D no VSCode
5. Rodar o projeto usando alt+L (padrão)

### Estrutura de pastas:
* src/core/ | Arquivos essenciais da engine
* src/game/ | Arquivos essenciais do jogo
* src/rendering/ | Arquivos para componentes e classes visuais
------------------------------------------------------------

### Scripts disponíveis
* love.exe main.lua - roda o jogo
